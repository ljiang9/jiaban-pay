# jiaban-pay · 国庆加班费计算器

2026 年国庆热点小工具：算算你国庆加班能拿多少钱，顺便换算成奶茶。

## 玩法

```bash
# 月薪 8000，国庆 10/1、2、3 加班
python3 -m jiaban_pay --salary 8000 --days 1,2,3

# 自定义奶茶单价
python3 -m jiaban_pay --salary 8000 --days 1,2,3 --milktea 20

# 终极抉择：加班 7 天 vs 请 3 天假拼出 13 天假期，哪个值
python3 -m jiaban_pay --salary 8000 --compare

# 不给 --days 会进入交互式提问（非终端下直接报错退出）
python3 -m jiaban_pay --salary 8000
```

日期支持 `1,2,3`、`1 2 3`、`1-3`、中文逗号多种写法。

## 计算规则（简化模型）

- 日薪 = 月薪 ÷ 21.75（月计薪天数）
- 10/1、10/2、10/3 为法定节假日：加班费 = 日薪 × 3
- 10/4、10/5、10/6、10/7 为休息日：加班费 = 日薪 × 2
- 时薪换算：每天按 8 小时计，加班 X 小时 ≈ 总额 ÷ 奶茶单价 杯奶茶

### 政策依据声明

本工具依据《工资支付暂行规定》第十三条的**简化口径**计算：法定休假日工作按 300% 另行支付、休息日工作按 200% 另行支付。
仅为娱乐估算工具，**不构成法律或薪酬建议**，实际以所在单位核算为准。

## 玩梗评语

| 情况 | 评语 |
|---|---|
| 7 天全加 | 你就是公司最靓的牛马！……但还是好好休息吧！ |
| 0 天加班 | 聪明人！好好享受假期 |
| 只加 10/1-3 | 精准拿下三倍，理财鬼才 |
| 只加 10/4-7 | 曲线救国专攻双倍 |

`--compare` 会算一笔账：7 天全勤加班费（17 倍日薪）vs 请 3 天年假拼出 13 天假期的「假期杠杆」，
最后给出不正经但真诚的结论。

## 诚实局限

- 简化模型：未考虑社保公积金、个税、加班调休折抵、综合工时制等实际情况
- 每天按 8 小时折算，真实加班时长以考勤为准
- 「假期杠杆」「奶茶换算」纯属娱乐，请勿用于跟 HR 谈判（后果自负）
- 纯文本 CLI，无图形界面；Python 3.10+，仅标准库
